# App Insight Analysis

## Project Overview

This project comprises the dataset from the Google Play Store, which contains information about various apps, including their ratings, genre, reviews, sizes, and more. 
We need to analyze this data to gain insights that can help improve businesses' app development strategies, enhance user experience, and increase app downloads and revenues.

## Objectives
1. Analyze the distribution of applications across categories and genre.
2. Compare free and paid applications.
3. Identify highly installed applications.
4. Analyze app ratings and review counts.
5. Study application size and pricing.
6. Explore the relationship between installations and ratings.
7. Analyze user-review sentiment.
   
## Dataset

Google Play Store application dataset supplemented with a user-reviews dataset.

Analysis Performed
Data cleaning and preprocessing.
Missing-value and duplicate analysis.
Cleaning of Size, Installs and Price fields.
Conversion of formatted values into numerical values.
Category and content-rating analysis.
Free versus paid application analysis.
Top application and installation analysis.
Rating and review analysis.
Relationship analysis between installs and ratings.
User-review sentiment analysis.
Visualizations

## Tools & Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Kaggle Notebook

## Key Skills

Data Cleaning, Feature Transformation, Categorical Analysis, Correlation Analysis, Sentiment Analysis and Data Visualization.
